# Built-in effects stay small

Built in: step reveal (`data-s`, `data-hide`, `.sN` classes), View Transitions, word rise on headings, count-up, typing, slide video, speakers.

Left out: effects that one talk needed (scramble, dot grids, fly-from, timelines, video zoom). Add them per deck. The `motion-design` skill helps with that.

Why: each built-in effect is code every deck carries. Only effects most talks use earn that place.
